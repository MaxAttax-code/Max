# The Max language

A language that was constructed as a multi-paradigm tool, easily integrable within projects. It's focused on being human-friendly, with cohesive language, and understandable keywords.
Although some aspects maybe prove to be verbose, we integrate *short-cut methods* that make code faster to write, alas less readable.

***

### VSCode Extension files

The language is highly unfinished, especially on the syntax highlighting aspects. However, it provides Vscodes **Intellisense**, as well built-in snippets, error highlighting, and quick fixes.
We would love to intake any requests or issues on the language in order to help us improve, although keep in mind that you will be able to find them commonly in this early version of the language.
